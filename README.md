FoodFinder-AI (Minor):
FoodFinder AI is a hybrid restaurant recommendation system designed to assist users in discovering dining options tailored to their unique preferences and geographical location. By integrating content-based filtering with collaborative filtering, the system ensures high accuracy and deep personalization. Restaurant attributes—including cuisine, price range, ratings, and amenities—are processed via TF-IDF vectorization and cosine similarity, while user interaction history refines suggestions through collaborative filtering. Experimental evaluations indicate that this hybrid approach generates significantly more relevant recommendations than single-model techniques, achieving enhanced user satisfaction.

SmartRide-AI (Minor):
AI-Based Uber/Rapido Fare Estimation System: SmartRide AI is a high-precision, machine-learning-driven platform engineered to eliminate pricing opacity in the modern ride-hailing ecosystem. By synthesizing historical trip data with real-time route dynamics—such as distance, traffic congestion, and passenger metrics—SmartRide empowers commuters with transparent, accurate fare projections before booking. Leveraging advanced ensemble regression models, specifically Random Forest and XGBoost, the system mitigates the unpredictability of dynamic pricing algorithms. The deployment of this solution via a Streamlit web application, integrated with the Google Maps API, serves as a benchmark for intelligent, transparent transportation technology.
